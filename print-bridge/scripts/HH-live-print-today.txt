----------------------------------------
STEP 4 — Start quick tunnel (LEAVE THIS RUNNING)
----------------------------------------

Open a NEW Terminal window on the Mini and paste:

Wait until you see a line like:

  https://something-random.trycloudflare.com

PHOTO that screen or copy the https URL.
Send / paste it to Cursor — needed for live deploy.

IMPORTANT:
- Leave this Terminal window open while testing.
- If you close it, printing from the iPad stops.
- After reboot you must run this again (permanent tunnel later).
