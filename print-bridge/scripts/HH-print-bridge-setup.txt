Houseplant Hospital — Mac Mini print-bridge setup
================================================

Do this ON the Mac Mini (fresh install is fine).

1. Open Terminal (Spotlight → type Terminal → Enter)

2. Copy EVERYTHING in the box below, paste into Terminal, press Return.
   (It will ask for your Mac password for Homebrew.)

------------------------------------------------------------
curl -fsSL https://raw.githubusercontent.com/RosannaCostello/Houseplant-Hospital/jack/hil-82-phase-4-macos-silent-print-integration/print-bridge/scripts/setup-mac-mini.sh | bash
------------------------------------------------------------

3. If it says Chrome is missing:
   - Install Chrome from https://www.google.com/chrome/
   - Run the same curl line again

4. When setup finishes, start the bridge:

------------------------------------------------------------
cd ~/Hilda/Houseplant-Hospital/print-bridge
npm run start
------------------------------------------------------------

Leave that window open.

5. Open a SECOND Terminal window and check health:

------------------------------------------------------------
curl -s http://127.0.0.1:8787/health
------------------------------------------------------------

6. Dry-run a label — first show the secret:

------------------------------------------------------------
cd ~/Hilda/Houseplant-Hospital/print-bridge
grep PRINT_BRIDGE_SECRET .env
------------------------------------------------------------

Then paste this, replacing YOUR_SECRET with the value from .env:

------------------------------------------------------------
curl -s -X POST http://127.0.0.1:8787/print \
  -H "authorization: Bearer YOUR_SECRET" \
  -H "content-type: application/json" \
  -d '{
    "plantId": "11111111-1111-4111-8111-111111111111",
    "caseUrl": "https://houseplanthospital.hildaedinburgh.workers.dev/hh/case/11111111-1111-4111-8111-111111111111",
    "customerSurname": "Smith",
    "plantName": "Monstera",
    "size": "Medium",
    "pestsFound": false,
    "checkedInAt": "2026-07-24T10:00:00.000Z"
  }'
------------------------------------------------------------

Open the htmlPath from the reply in Chrome (File → Open File).

7. Real print: edit .env and set PRINT_MODE=print

------------------------------------------------------------
open -e ~/Hilda/Houseplant-Hospital/print-bridge/.env
------------------------------------------------------------

Change PRINT_MODE=dry-run to PRINT_MODE=print, save.
In the first Terminal: Ctrl+C, then:

------------------------------------------------------------
cd ~/Hilda/Houseplant-Hospital/print-bridge
npm run start
------------------------------------------------------------

Run the same POST curl again — label should print on HH_Airprint.

Printer name: HH_Airprint
Label size: 60x86mm
